# Sprocket — Shared

Target-agnostic Gleam project for contracts and utilities shared by the server and browser runtimes.
Currently contains placeholder modules that will be replaced in upcoming phases.

## Commands

- `gleam build` — compile for BEAM.
- `gleam test --target javascript` — run shared tests against the JS target.

Use root `yarn shared:test` to run the JS test target from the repository root.
