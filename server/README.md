# Sprocket — Server (BEAM)

BEAM-targeted Gleam project containing the Sprocket runtime, HTML DSL, hooks, and renderers.

## Commands

- `gleam build` — compile for Erlang/OTP.
- `gleam test` — run gleeunit suites in `test/`.

This project depends on `../shared` for cross-target contracts. Use root `yarn server:build` or run commands from this directory.
